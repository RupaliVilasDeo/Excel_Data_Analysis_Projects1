# Excel Data Analysis Projects

## 📊 Project Overview

This repository contains two Microsoft Excel data analysis projects demonstrating practical skills in data analysis, Pivot Tables, financial reporting, and dashboard creation.

The projects focus on analyzing production performance and business transactions to summarize key metrics and support data-driven decision-making.

* Microsoft Excel
* Data Analysis
* Pivot Tables
* Data Cleaning and Data Organization
* Revenue, Expense and Profit Analysis
* Production Cost Analysis
* Data Summarization
* Dashboard Creation
* Business Reporting
* Data Visualization

## 📁 Projects Included

### 1. Production Data Analysis & Dashboard

This project focuses on analyzing production data using Excel formulas, Pivot Tables, and a dashboard.

**Key Analysis:**

* Production cost analysis
* Units produced by year
* Product-wise production cost analysis
* Manager-wise task analysis
* Average production cost per unit
* Production performance reporting

**Skills Demonstrated:** Excel formulas, Pivot Tables, data analysis, and dashboard creation.

### 2. Business Transaction & Financial Analysis

This project analyzes business transaction data to understand revenue, expenses, profit, and transaction patterns across different business dimensions.

**Key Analysis Using Pivot Tables:**

1. **Total Profit by Payment Method**
   Analyzes profit generated through different payment methods.

2. **Total Revenue by Product Line**
   Compares revenue across different product lines.

3. **Total Revenue, Expenses and Profit by Category**
   Compares financial performance across business categories.

4. **Number of Transactions by Region**
   Identifies transaction volume across different regions.

5. **Average Expense for Each Category**
   Compares average expenses across business categories.

**Business Objectives:**

* Understand revenue and profit distribution.
* Compare expenses across categories.
* Identify product lines contributing to revenue.
* Analyze regional transaction activity.
* Evaluate average expenses by category.
* Support business reporting through summarized data.

**Skills Demonstrated:** Excel Pivot Tables, financial data analysis, business metrics, data summarization, and reporting.
